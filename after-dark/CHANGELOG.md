# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [0.1.0] — не выпущено (прототип)

### Добавлено
- Структура репозитория по техническому заданию.
- Ядро: настройки игрока с проверкой значений, модульные переключатели, логирование.
- Сохранение состояния: номер схемы, загрузка без исключений, изоляция повреждённых записей.
- Система согласия: предложения с явным ответом, проверка возраста 18+.
- История отношений и правила завершения (расставание и предательство).
- Репутация: публичная, в кругу друзей, профессиональная, известность.
- Флирт: кулдаун на партнёра и дневной лимит.
- Черновики тюнинга: черта «Жажда новых впечатлений», три взаимодействия флирта, строки en/ru.
- 45 модульных тестов, скрипт проверки репозитория, CI.

### Известные ограничения
- Тюнинг XML — черновик, не проверен в Sims 4 Studio и в игре.
- Игровые хуки (сохранение, выдача черты, взаимодействия) не реализованы.
- Сборка `.ts4script` не реализована.
- Совместимость с версиями игры не проверена.

# AFTER DARK — мод для The Sims 4

> **18+.** Мод предназначен только для совершеннолетних персонажей (все взрослые
> механики требуют возраста 18 лет и старше). Тематика взрослая.

**Версия:** 0.1.0 (прототип) · **Статус:** в разработке, **не проверен в игре** ·
**Название первого релиза:** AFTER DARK 0.1.0 — Relationships & Reputation

AFTER DARK добавляет в The Sims 4 взрослую линию жизни: флирт и знакомства,
договорённости о связях, историю отношений, репутацию, общественную реакцию
и последствия решений. Главная героиня — Виктория Блэйк (25 лет) — открыто
живёт по своим правилам. Её характер не означает автоматического штрафа:
мод не наказывает персонажа за сексуальные предпочтения или количество связей.

## Что есть в версии 0.1.0

- Ядро: настройки игрока с проверкой значений, логирование, сохранение состояния
  с номером схемы и защитой от повреждённых данных.
- Согласие: предложения (свидание, связь, моногамия) требуют явного ответа;
  отказ не даёт штрафов; все участники должны быть 18+.
- История отношений: каждая связь сохраняется, в том числе завершённая.
- Завершение отношений: расставание по согласию и предательство имеют разные последствия.
- Репутация: три оси (публичная, в кругу друзей, профессиональная) и известность;
  изменения только через события, с учётом публичности.
- Флирт: кулдаун на партнёра и дневной лимит, чтобы исключить бесконечные циклы.
- Черта «Жажда новых впечатлений» — **черновик тюнинга**, не проверен в игре.
- Автоматическая проверка репозитория и 45 модульных тестов вне игры.

Подробности — в [docs/GAMEPLAY_SYSTEMS.md](docs/GAMEPLAY_SYSTEMS.md).
Чего пока нет — в [docs/ROADMAP.md](docs/ROADMAP.md).

## Установка

**Пока недоступна.** Первая собранная и проверенная в игре версия ещё не опубликована.
Инструкция по установке появится в GitHub Release вместе с архивом мода.
Не устанавливайте сборки из неизвестных источников.

## Совместимость

Версия игры, с которой мод проверен, **пока не определена**. Совместимость с
какой-либо версией The Sims 4 и дополнениями не гарантируется.
См. [docs/COMPATIBILITY.md](docs/COMPATIBILITY.md).

## Разработка

```bash
# Тесты логики (не требуют игры)
python -m pip install pytest
python -m pytest

# Проверка репозитория: синтаксис, XML, строки, версии, отсутствие игровых ресурсов
python tools/validate_repo.py
```

Структура репозитория:

```
after-dark/
├── src/after_dark/      # Python-код мода
│   ├── core/            # настройки, логирование, сохранение, состояние
│   ├── systems/         # sexuality, relationships, reputation
│   └── integrations/    # мост к игре (пока без проверенных хуков)
├── tuning/              # XML-тюнинг, строки (черновики)
├── tests/               # модульные тесты
├── tools/               # проверки и вспомогательные скрипты
├── docs/                # архитектура, системы, совместимость, план
└── .github/             # CI и шаблоны задач
```

## Правила и ограничения

- Не используются и не распространяются чужие игровые ресурсы.
- Игровые файлы (`.package`, `.ts4script`) и архивы не хранятся в git.
- Мод не собирает персональные данные игрока.
- Мод не изменяет исходные файлы игры.
- Все функции можно отключить в настройках.

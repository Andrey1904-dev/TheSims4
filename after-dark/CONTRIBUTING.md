# Как помочь проекту

## Правила, которые нельзя нарушать

1. **Только совершеннолетние.** Любая взрослая механика проверяет возраст 18+.
   Тесты для этого обязательны (см. `tests/test_consent.py`).
2. **Согласие.** Интимные или романтические действия не запускаются автоматически
   и не возникают из случайных событий. Нужен явный ответ участника.
3. **Без морального штрафа за предпочтения.** Сексуальные предпочтения, открытость
   и число связей не должны автоматически менять репутацию, доверие или характер.
4. **Не ломать сохранения.** Изменения формата сохранения — через `SAVE_SCHEMA_VERSION`
   и миграцию. Загрузка должна работать с данными прошлых версий.
5. **Без чужих ресурсов.** Не добавлять чужие `.package`, сборки и текстуры без разрешения автора.
6. **Не собирать персональные данные.**

## Процесс

1. Создайте задачу по шаблону в `.github/ISSUE_TEMPLATE/`.
2. Работайте в отдельной ветке, не в `main`.
3. Перед PR выполните:
   ```bash
   python -m pytest
   python tools/validate_repo.py
   ```
4. Для изменений тюнинга или поведения в игре приложите результаты проверки в игре
   (шаблон «Отчёт о проверке в игре»).
5. Обновите `CHANGELOG.md` в разделе «Unreleased» или текущей версии.

## Стиль

- Python 3.7+ (совместимость с версией Python, которую использует игра, проверяется
  отдельно — см. docs/COMPATIBILITY.md). Не используйте `match`, `|` в аннотациях вне
  `from __future__ import annotations`.
- Логика систем — без обращений к API игры; интеграция — только в `integrations/`.
- Тексты для игрока — только через ключи в `tuning/strings/`.

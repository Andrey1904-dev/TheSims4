# Архитектура

## Слои

```
┌──────────────────────────────────────────────┐
│ integrations/  — мост к игре (The Sims 4 API) │  ← единственное место с кодом игры
├──────────────────────────────────────────────┤
│ systems/       — игровая логика              │
│   sexuality/    согласие, флирт              │
│   relationships/ история связей, правила     │
│   reputation/   репутация, события           │
├──────────────────────────────────────────────┤
│ core/          — настройки, состояние,       │
│                  сохранение, логирование     │
└──────────────────────────────────────────────┘
```

Правило зависимостей: слой выше может импортировать слой ниже, но не наоборот.
`core` и `systems` не импортируют игровые модули — поэтому тестируются вне игры.

## Состояние и сохранение

`ModState` хранит состояние по ID персонажа (`SimRecord`): историю связей,
репутацию, лимиты флирта. `dump_state` превращает его в JSON-совместимый словарь
с полем `schema_version`. `load_state` никогда не выбрасывает исключение:
повреждённая запись пропускается с предупреждением.

Параметры флирта не сохраняются в файл: при загрузке берутся из текущих настроек.
Так изменение настроек не требует миграции.

## Настройки

Настройки — словарь с проверкой (`core/settings.py`). Неверные значения заменяются
значениями по умолчанию, а не вызывают ошибку. Главный переключатель
`adult_mechanics_enabled` отключает все взрослые механики, но не ядро.

## Интеграция с игрой

Не реализована. Точки интеграции перечислены в `integrations/sims4_bridge.py`.
Каждая будет добавлена только после проверки в игре.

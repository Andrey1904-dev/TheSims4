# Совместимость

## Версия игры

**Не определена.** Мод не проверялся в игре, поэтому совместимость с любой версией
The Sims 4 не заявляется. Перед первым релизом будет зафиксирована точная версия
игры и список дополнений, на которых проведена проверка.

## Дополнения

Цель: работа без дополнительных DLC. Фактическая проверка не проведена.
Если для отдельных механик понадобится пакет, это будет указано как зависимость.

## Python

Игра исполняет Python-код встроенного интерпретатора, версия которого зависит от
версии игры. Код мода пишется на Python 3.7+ без новых возможностей. Версия
интерпретатора в игре будет подтверждена при первой проверке.

## Другие моды

Конфликты с другими модами не проверялись. Мод не должен переопределять
стандартные функции и тюнинг игры; изменения ограничиваются новыми ресурсами.

## Проверка перед релизом

Проверка выполняется в игре по сценарию из раздела «Тестирование» технического задания.
Результаты записываются по шаблону `.github/ISSUE_TEMPLATE/game_test_report.md`.
